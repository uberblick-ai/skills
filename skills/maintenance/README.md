# Maintenance

Repository maintenance skills, independent of a delivery loop or release process. Plugin: `maintenance`.

- [backlog-grooming](backlog-grooming/SKILL.md): Review repository, milestone or project issues for unnecessary work, duplication and scope reductions, grounded in current deliveries and available product intent; produce an actionable decision report.
- [ci-health](ci-health/SKILL.md): Track CI on main from GitHub Actions for any repository: median wall time per parallel job and in total with its spread and P95, the test count, optional coverage and code against test lines, and the changes that made CI slower or faster; stores each day in the repository's own Uberblick document when the MCP tools or `ub` are there.
